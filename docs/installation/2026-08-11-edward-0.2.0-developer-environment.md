# Edward 0.2.0 开发环境手动部署指南

本指南只列出不妥协的完整依赖路径。完成后再开始实施；不要用系统自带旧库或缺少 MLT/Qt 的替代方案。准确版本、提交、许可证、前缀、FFmpeg/MLT 构建能力和 CMake 发现规则以 `docs/contracts/dependency-lock.md` 为准；本文件只说明开发者需要手动完成的部署动作。

## macOS（Apple Silicon）

前置条件：Xcode 与 Homebrew 已可用。本机应具备 CMake、Ninja、pkgconf、nlohmann-json、已核验的 GPL FFmpeg、MLT、whisper.cpp、DOCX/PDF 解析与签名验证依赖，以及官方 Qt 6.11.1。2026-08-11 的当前开发机已实测 `whisper-cpp 1.9.2`、`libzip 1.11.4`、`pugixml 1.16`、`Poppler 26.08.0`、`libsodium 1.0.22`；以下命令保留为可重复部署和验证路径。

```sh
brew install mlt whisper-cpp libzip pugixml poppler libsodium
brew upgrade whisper-cpp
```

若阿里云 bottles 镜像报告 Poppler 缺少瓶包或下载长期无进展，使用已核验存在该瓶包的中科大镜像重试同一公式，不能省略 Poppler：

```sh
HOMEBREW_NO_AUTO_UPDATE=1 \
  HOMEBREW_BOTTLE_DOMAIN=https://mirrors.ustc.edu.cn/homebrew-bottles \
  brew install poppler
```

验证：

```sh
brew info mlt --json=v2
pkg-config --modversion mlt-framework-7
ffmpeg -buildconf
test -f "$(brew --prefix nlohmann-json)/include/nlohmann/json.hpp"
whisper-cli --help
brew list --versions whisper-cpp | rg -q '^whisper-cpp 1\.9\.2$'
pkg-config --modversion libsodium
pdftotext -v
```

使用 [Qt 官方在线安装器](https://www.qt.io/download-qt-installer) 安装依赖锁定合同指定的 Qt `6.11.1` 的 `Desktop` 平台包、Qt Shader Tools 与 Qt Multimedia。安装目录可保持默认 `~/Qt`；安装完成后 Qt 根目录应为 `~/Qt/6.11.1/macos`。不得用 Homebrew 的浮动 Qt 版本替代该锁定版本。

配置 Edward 时传入：

```sh
export EDWARD_QT_ROOT="$HOME/Qt/6.11.1/macos"
pkg-config --modversion mlt-framework-7
pkg-config --modversion libavformat
cmake --preset macos-debug \
  -DQt6_ROOT="$EDWARD_QT_ROOT/lib/cmake/Qt6"
```

## Windows 11 x64

安装 Visual Studio 2022 Community 的“使用 C++ 的桌面开发”工作负载，并勾选 MSVC v143、Windows 11 SDK、C++ CMake tools for Windows。安装 CMake 与 Ninja 后，使用 Qt 官方在线安装器安装 Qt 6 的 `MSVC 2022 64-bit`、Qt Declarative/QML、Qt Shader Tools 与 Qt Multimedia 组件。

FFmpeg、MLT、whisper.cpp、libzip、pugixml、Poppler 和 libsodium 必须使用同一 MSVC x64 工具链、同一 `C:\edward-deps\0.2.0` 前缀，从 `dependency-lock.md` 固定的源码 tag/commit/归档 SHA-256 构建；不得混用 MinGW 二进制、未知许可证预编译包或仅运行时 DLL。构建产物必须提供 FFmpeg 的 `libavformat`/`libavcodec`/`libavfilter` 开发头文件、导入库、DLL、pkg-config `.pc` 文件，以及 MLT/MLT++ 头文件、导入库、DLL、modules 和 `.pc` 文件。

推荐目录：

```text
C:\edward-deps\0.2.0
C:\edward-tools\pkgconf\bin
C:\src\vcpkg
```

用 vcpkg 安装纯头文件 JSON：

```powershell
git clone https://github.com/microsoft/vcpkg C:\src\vcpkg
C:\src\vcpkg\bootstrap-vcpkg.bat
C:\src\vcpkg\vcpkg install nlohmann-json:x64-windows
```

配置 Edward 时使用：

```powershell
cmake --preset windows-debug `
  -DQt6_ROOT="C:\edward-deps\0.2.0\qt\lib\cmake\Qt6" `
  -DPKG_CONFIG_EXECUTABLE="C:\edward-tools\pkgconf\bin\pkgconf.exe" `
  -DCMAKE_PREFIX_PATH="C:\edward-deps\0.2.0;C:\src\vcpkg\installed\x64-windows" `
  -DCMAKE_TOOLCHAIN_FILE="C:\src\vcpkg\scripts\buildsystems\vcpkg.cmake"
```

部署完成后运行 `cmake --build --preset windows-debug` 与 `ctest --preset windows-debug --output-on-failure`；再用安装包 smoke 验证 FFprobe、MLT avformat module、QML 和 1080p 导出。任一依赖未被 CMake 发现时，先按锁定合同修复前缀、`.pc` 文件或同工具链构建，不准删掉该依赖或改用功能较弱的替代品。
