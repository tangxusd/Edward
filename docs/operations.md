# 使用与运维

模型 API 地址、模型标识和凭证引用由用户在应用内设置。凭证仅保存于本地应用数据目录，不写入项目文件、风格包或导出文件。

每次 AI 语义分析成功后，计划会保存为项目 `ai-plans/` 目录下的独立快照。编辑器中的“已保存 AI 计划”可将任一快照重新载入计划文本框；应用时间线前仍由用户手动选择应用方式。

资源库中的导入资源支持搜索、收藏和移出。移出操作只更新资源库索引并保留导入文件，不会删除用户素材；需要再次使用时可重新导入风格包。

普通导出为 MP4/HEVC/AAC。透明导出为 MOV/ProRes 4444。导出由用户手动发起，可选择目录、画幅和分辨率，并可取消。

离线编辑窗口为最近有效授权后的两小时；触发 AI 分析时必须检查授权。生产订阅服务、设备绑定和支付域名尚未配置，因此当前授权模块只提供本地策略。

订阅、支付、账号体系和平台签名服务暂不开发；后续仅在明确外部服务方案与授权后恢复实现。

FFmpeg、FFprobe 和 Python/faster-whisper 运行时尚未随安装包分发。缺失时应用会给出明确诊断；发布独立安装包前必须补齐 macOS 与 Windows 的二进制、模型权重和许可证归属。

定期备份项目工作目录。恢复项目时，若媒体路径失效，应重新定位原始素材。
