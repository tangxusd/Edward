# Edward 0.2.0 原生标题栏桥接合同

Edward 所有页面锁定深色系统标题栏；应用内容区不得再创建标题栏。桥接层只在标题栏安全区域提供保存状态、项目名称、模型/在线状态、设置和导出入口，窗口控制仍由系统拥有。

## 平台职责

- macOS：使用原生标题栏 accessory/safe-area 承载 QML 标题栏内容，避开红黄绿窗口控制区域。双击未被交互控件占用的原生标题栏区域仍交给系统缩放；系统拖动区域不得被 QML 抢占。
- Windows：使用原生非客户区扩展/安全区承载相同 QML 内容，避开最小化、还原/最大化、关闭按钮。命中测试优先把系统控制区、双击、拖动交回窗口管理器。
- 共享 QML 只声明语义锚点 `titlebarLeadingSafeArea`、`titlebarCenterSafeArea`、`titlebarTrailingSafeArea`；不得假定像素高度、窗口控制宽度或平台按钮图形。

## 交互与验证

- 可交互控件必须使用真实键盘焦点、可访问名称和 Tab 顺序；非交互状态文字不拦截拖动/双击。
- 首页与工作台均使用同一桥接；工作台只能显示已确认的保存、项目名、模型、设置、导出，首页只保留设置与登录等该页面已确认入口。
- macOS/Windows 都要有原生双击缩放、拖动窗口、窗口控制点击和标题栏控件点击的自动 smoke；视觉截图不把平台控制按钮作为跨平台像素相同的比较区域。
