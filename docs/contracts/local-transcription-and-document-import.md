# Edward 0.2.0 本地转写与文稿导入合同

## 范围与非范围

创建项目时接受 TXT、Markdown、DOCX、可复制文本 PDF、SRT。主音频或视频必选，文稿可选；没有文稿才执行本地转写。扫描版 PDF 不 OCR，必须返回“该 PDF 不含可复制文本，Edward 0.2.0 不提供 OCR”。只支持中文和英文；不分说话人，不做多音轨转写。

禁止将文稿或音视频上传给第三方转换服务。云端模型只接收已得到的文稿/转写文本进行语义分析。

## 锁定依赖与模型

- 转写运行时：`whisper.cpp v1.9.2`，见 `dependency-lock.md`。
- 默认模型：经 SHA-256 验证的 `large-v3-turbo` GGML 质量档；首次需要时完整下载，不以较小模型替代。模型下载、版本、哈希、许可和实际量化文件名必须写入本地依赖 manifest；模型不可用即创建流程失败并提供重试/取消。
- 模型运行优先使用已实际探测的 Metal（macOS）或 CUDA/Vulkan/CPU（Windows）后端；后端不可用可以使用同一锁定模型的 CPU 路径，不得切换为较小模型。性能夹具必须在两台基准机记录转写耗时和峰值内存。
- DOCX：libzip 1.11.4 + pugixml 1.16，仅读取 ZIP 内 `word/document.xml` 的文本节点；拒绝宏、嵌入对象、外链和超出受限解压大小/条目数的文件。
- PDF：Poppler 26.08.0 的文本提取 API；仅接受成功提取的 Unicode 文本，不对图片或空文本猜测 OCR。

## 输出与时间对齐

- 转写输出保存为项目 `ai/transcript.md`，包含 UTF-8 正文和每段 `startFrame`/`endFrame`；帧号由时间戳按 30 fps 四舍五入并单调修正。
- 字幕断句直接使用转写段与标点规则；文稿存在时，文稿文字为语义分析优先输入，转写时间戳仍用于字幕/时间线对齐。
- 本地转写完成后，AI 初版使用产生的结果；不保留独立的可编辑本地转写工作流，不抽取视频关键帧。

## 安全与失败

- 所有解析都限制输入文件大小、解压后总大小、XML 深度、页面数和单段文本长度；失败返回格式、损坏、超限或无可复制文本的明确错误。
- 文稿解析、转写、时间戳归一化均有固定中英文夹具、损坏 DOCX、ZIP bomb、扫描 PDF、SRT 非法时间和缺音频流测试。
- 任何失败保留工程记录和受管副本，停留在创建页，只允许重试或取消；不得进入不完整工作台。
