# Edward 外部插件沙盒合同

## 目标

Remotion 与 HyperFrames 外部适配器只处理单次任务的受控输入和输出。插件不是工程、用户目录、网络或 Edward 进程权限的继承者。

## 每次任务的最小权限

| 位置 | 权限 | 用途 |
| --- | --- | --- |
| 已验证插件根目录 | 只读 | 用户独立安装的适配器代码与锁定依赖 |
| Edward 固定 Node 运行时 | 只读并执行 | 经 SHA-256 与版本校验后的解释器 |
| 任务输入目录 | 只读 | 宿主复制的媒体、缩略图或 JSON 输入 |
| 任务输出目录 | 只写 | Component IR 草稿、透明帧、导出产物与受限日志 |
| Chromium 共享运行时缓存 | 只读 | 已完成来源与版本校验的浏览器运行时；首次下载只能由 Edward 主进程完成，插件不可下载或更新 |
| 任务专属 Chromium 临时目录 | 读写 | 浏览器启动所需的临时 profile；任务结束必须删除 |

其它所有文件系统位置都必须拒绝，包含项目根目录、全局缓存、资源库、认证令牌、模型配置、用户主目录、系统凭证与 Edward 引擎写目录。

## 网络与进程

- 插件进程及其 Node、Chromium 子进程树一律不得访问网络。
- 插件不得创建子进程、读取继承环境中的密钥或访问系统 Keychain/Credential Manager。
- 超时、取消或协议违规时，宿主必须终止整个子进程树并删除任务临时目录。

## 平台要求

- macOS：正式版由原生最小权限执行器启动，不使用普通 `QProcess` 或 `sandbox-exec` 冒充发布级隔离。
- Windows：正式版由 AppContainer 启动，并只为上述任务目录配置 ACL；没有 AppContainer 能力时拒绝启动外部插件。
- Debug：可用于本地适配器开发，但界面必须表明其不是发行级隔离，且不得作为 Release 回退路径。

## 验收测试

每个平台都必须验证：允许读取任务输入、允许写入任务输出、拒绝读取工程外哨兵文件、拒绝写入工程外哨兵文件、拒绝网络连接，并在超时后确认子进程树不再存活。
