# Edward 0.2.0 RenderGraph 合同

## 唯一画面真相

`RenderGraph::build(const ProjectSnapshot&, const RenderRequest&)` 是预览、离屏帧、代理和导出的唯一画面求值入口。它使用整数工程帧号（30 fps）和 Rec.709 SDR 工作空间，不读取 QML 状态，也不允许调用方临时改写组件、字体、关键帧、转场、黑边或混音。

`ProjectSnapshot` 必须已包含受管原始媒体引用、色彩探测元数据、片段时间映射、组件实例/内部节点、关键帧、转场、资源锁定、字幕、标记和参考线。标记与参考线只用于交互显示，绝不成为导出图层。

## 不可变渲染场景

构建结果为不可变 `RenderScene`，顺序固定如下：

1. 对每个媒体源依据其探测元数据产生 Rec.709 转换节点；原始 `media/` 字节永不修改。
2. 按轨道/片段/转场的工程顺序产生视频和音频源节点；缺失素材使用确定性占位节点。
3. 以同一坐标系求值组件容器、内部文字/图表/标注/数字节点、字体回退、关键帧和字幕。组件关键帧使用 `工程帧 - 组件时间线起始帧` 的本地帧；组件范围外不求值、不显示。
4. 进行黑边、完整显示、裁剪、混音和输出像素格式处理。

每个可见节点必须具有稳定 `nodeId`、整数开始/结束帧、画布坐标、变换矩阵、裁剪区域、颜色和已求值动画属性。组件的预览选择框、控制点、吸附线与鼠标命中只能由桌面层叠加，不能参与 `RenderScene` 或导出。

## 后端边界

- `edward_core` 只生成 `ProjectSnapshot` 与动画求值结果。
- `edward_media` 将 `RenderScene` 映射到 MLT/FFmpeg 的解码、时间映射、音频和帧合成路径，并在同一调用中完成组件/字幕像素合成。
- Qt/QML 只显示 `edward_media` 交付的最终帧，并在其上绘制非导出交互覆盖层；它通过命令 API 请求选择、拖拽、缩放、吸附与关键帧编辑，不能自行渲染第二套组件内容。
- 预览、离屏渲染、代理与导出必须使用同一 `RenderScene`。预览质量仅可换用已就绪代理媒体或降低输出分辨率；不得改变场景节点、时间、颜色转换、字体或动画求值。

## 坐标、颜色与一致性

- 画布坐标使用项目画幅像素；预览显示矩形与画布之间使用唯一 `CanvasTransform`。命中测试、拖拽、缩放、参考线和吸附均先逆变换到画布坐标后提交命令。
- 视频输入首先依据 FFprobe/解码器色彩元数据转换到 Rec.709 SDR。元数据缺失或转换无法确定时返回显式错误；不得默认猜测后静默导出。
- 文本、组件和素材层均在同一 Rec.709 SDR 合成空间内输出。代理可降低分辨率，但不得重新解释颜色。
- 同一 `ProjectSnapshot`、`frame`、输出尺寸与请求范围产生确定性的层级和节点参数。视觉验收至少比较预览捕获帧与离屏帧；像素容差、字体和平台基线由 `visual-route-baseline.md` 管理。

## 必测拒绝条件

1. 导出请求引用代理媒体；
2. QML 覆盖层被写进 RenderScene；
3. 缺失色彩转换信息却继续导出；
4. 预览与离屏对相同工程帧求出不同节点顺序、关键帧值或字体回退；
5. 非整数工程帧进入核心求值。
