- 目的：验证 React、GSAP、HTML/CSS、SVG 组件在 FableCut 中的时间线插入、属性编辑、预览与逐帧导出入口。

## 2026-09-14（动画与变换修正）

- 动画统一为单方向描边闭合：0.5 秒内使用三次方缓出，组件默认时长 3 秒，后续时间保持闭合状态。
- 组件中心改为按输出视口的归一化 `x/y` 计算，默认值为 `(0.5, 0.5)`；缩放同时作用于包围盒和原生绘制尺寸。
- 拖拽改为写入归一化坐标，缩放继续写入 `scale`，指针移动期间立即重绘组件层，避免 DOM 预览残留或消失。
- 导出逐帧调用同一组件入口的 `export` 模式，并传入输出视口；已完成静态契约和测试自检，未替代人工画面验收。

## 2026-09-15（坐标、单向动画与拖放修正）

- React、GSAP、HTML/CSS 改为与 SVG 相同的原生 SVG 描边路径，统一使用单方向 `stroke-dashoffset`，避免双向闭合。
- `x/y` 统一为以画布中心为零点的像素值；组件中心使用 `画布尺寸 / 2 + x/y`，不再使用归一化小数坐标。
- 组件层根据画布 CSS 显示尺寸做缩放映射，修复预览偏左上问题。
- 标注资源支持拖入时间线，也支持直接拖入预览画布，落点转换为中心零点像素坐标。
- 验证：FableCut 完整测试 67/67 通过，所有相关 JavaScript 语法检查通过。

## 2026-09-15（资源实例、冲突与导出自检）

- 组件运行时在播放头切换时先移除失效实例，避免轨道片段显示为其他组件。
- 同一轨道插入或拖动片段时执行区间冲突检测；发生重叠则拒绝插入或恢复拖动前状态。
- 四种标注组件动作时间统一为 1 秒，总片段时长默认 3 秒。
- 原生组件导出继续通过逐帧 `prepareFrame` 和同一直接运行时；代码级检查确认 `export` 模式和输出视口传递完整。
- 验证：FableCut 完整测试 67/67 通过；未使用浏览器自动化工具，实际 MP4 文件仍需在 Edward 界面执行一次人工验收。

## 2026-09-15（导出与轨道放置修正）

- 原生标注组件导出改为直接序列化当前 SVG 节点到输出 SVG，再绘制到导出画布，避免 foreignObject 导致新组件在视频中缺失。
- 资源库拖拽幽灵改为时间线片段样式，便于根据时间尺和轨道落点定位。
- 组件发生轨道冲突时自动向上一层视频轨道寻找空位；所有上层均冲突时自动创建新视频轨道。
- 验证：FableCut 完整测试 68/68 通过，相关语法检查通过。

## 2026-09-15（原生矩形导出坐标修正）

- 根因：导出合成曾按组件 host 的整层包围盒计算，且可见性只检查内联 `display`；原生 SVG 节点的实际位置在导出时可能被外层容器吞掉，导致 React、GSAP、HTML/CSS、SVG 矩形均不进入视频。
- 修正：导出合成改为按每个可见原生 SVG 节点的实际 `getBoundingClientRect()`，直接换算到输出宽高并序列化为输出 SVG，再绘制到导出画布；可见性改用计算样式判断。
- 验证：`node --check third_party/FableCut/component-runtime.js` 通过；FableCut 完整测试 68/68 通过；导出契约新增实际 SVG 包围盒和输出尺寸断言。
- 未覆盖：当前环境未运行 Edward 内的人工 MP4 导出回放，需在界面中分别导出四种矩形并检查文件画面。

## 2026-09-15（异步组件实例残留修正）

- 根因：播放头快速切换时，旧组件仍处于异步 `mount` 状态；组件实例已销毁但其 host 未移除，导致 Card 6 的 DOM 残留覆盖后续所有闭合矩形预览。
- 修正：异步挂载完成后若片段已失效，统一销毁实例并移除 host；生成代次失效的同类路径同步清理。
- 验证：新增“异步组件挂载残留 host 必须移除”回归断言；FableCut 完整测试 68/68 通过，JavaScript 语法检查通过。

## 2026-09-15（预览、导出命名与监视器标尺）

- 根因：原生组件层尺寸取自整个监视器内层而不是实际画布，SVG 因此无法严格居中；导出混合原生 SVG 与 Card 6 时只绘制其中一类；结束导出时直接 `rename`，同名文件可能被替换。
- 修正：组件 overlay 绑定到预览画布的实际屏幕矩形；导出同时合成原生 SVG 与旧 DOM 组件；最终文件使用排他硬链接落盘，遇到同名自动生成不覆盖的序号文件。
- 界面：监视器画布上侧和左侧增加以中心零点为基准的像素标尺。
- 验证：新增混合组件导出、文件名排他落盘和监视器布局代码检查；JavaScript 语法检查通过。

## 2026-09-15（冲突落盘与固定边框标尺修正）

- 根因：macOS 当前文件卷不支持对 `.part` 文件执行硬链接，导致导出结束阶段报 `ENOTSUP`；标尺仍以预览画布矩形定位，随画布偏移。
- 修正：改用 `COPYFILE_EXCL` 原子排他复制，冲突时递增文件名且绝不覆盖；标尺固定在监视器边框左上角，刻度间隔改为 10 像素，标注每 100 像素。
- 验证：新增文件落盘和固定标尺回归断言；JavaScript 语法检查和 FableCut 测试通过。
