# 0.7.0 原生运行时迁移

## 目标

彻底移除 DaVinci Resolve、Fusion、Premiere 和 Component IR 代码；组件预览、参数编辑和导出只使用 `edward.web-runtime.v1` 清单、原生入口与 props。

## 影响范围

- `WorkbenchRuntime`：删除 Resolve 连接、动作、导出、轮询和旧 IR 节点编辑状态；只保留 `NativeRuntimeComponent`。
- `Workbench.qml`：删除 Resolve 面板和旧节点属性控件，改为由 `propsSchema` 与 `editableProperties` 驱动。
- 项目读写：删除 `component` 字段，仅保存 `nativeRuntime`。
- 测试与打包：删除旧测试和资源断言，保留 Web Runtime 清单、预览与导出验证。

## 验收

1. 生产源码、CMake、测试、脚本与资源中不存在目标遗留技术的运行时引用。
2. 四种原生运行时组件清单仍可被读取。
3. `edward_app` 全量构建通过。
4. `.edward/acceptance/current.json` 的所有检查标记为通过。
