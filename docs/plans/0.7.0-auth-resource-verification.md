# 0.7.0 认证与资源库验证

## 目标

确保 Edward 登录后的 FableCut 资源库请求携带同一份 Supabase 会话，并在不依赖真实账号的前提下验证本地代理合同。

## 已完成

1. 登录成功后将 `access_token` 保存到 `fablecut-auth-session`。
2. 资源库请求从该会话构造 `Authorization: Bearer <token>`。
3. 本地服务将 Bearer token 与匿名公钥转发到 Supabase 资源目录端点。
4. 受控本地上游替身测试验证请求路径、Bearer token、匿名公钥和响应透传。

## 外部完成门

1. 使用专用 Supabase 测试账号登录 Edward，验证资源分类、目录、详情和收藏的 RLS 行为。
2. 绑定支付平台后，验证真实扣款、续订、退款及 webhook 幂等处理。

这些步骤会创建或读取外部账号、权益和支付状态，必须在提供测试账号与支付平台配置后执行。
