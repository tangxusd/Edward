# Edward 0.2.0 发布、许可证与性能验收实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` task-by-task.

**Goal:** 交付 macOS/Windows 可安装包、GPL 合规材料、基础资源与可复验性能报告。

### Task 1: 打包与 GPL 通知

**Files:** Create `packaging/macos/Package.cmake`, `packaging/macos/entitlements.plist`, `packaging/windows/Package.cmake`, `packaging/windows/installer.wxs`, `licenses/THIRD_PARTY_NOTICES.md`, `licenses/GPL-3.0.txt`, `tests/packaging/test_bundle_contents.cpp`.

**Consumes:** 01–07 的正式产物、G-01 基础字体工件、基础组件包及许可证清单。

**Produces:** 可检查 macOS `.app`/安装包与 Windows 安装包的 CMake 打包定义，及 bundle 内容验证。

- [x] **Step 1: 写失败测试**:

```cpp
void test_IncludesFfmpegMltLicensesAndBaseResources() { QVERIFY(bundleHas("licenses/GPL-3.0.txt")); }
```

- [x] **Step 2: 验证失败**：已用 `packaging.macos_package_gate` 验证缺少真实许可证、第三方声明、基础资源和 MLT 运行时输入时拒绝打包。
- [ ] **Step 3: 最小实现**：打包 Edward、Qt 运行时、GPL FFmpeg/MLT、许可证、第三方通知、基础字体和基础组件；资源库下载内容不放入源码仓库或基础包。
- [ ] **Step 4: 验证通过**：重跑测试，预期缺少许可证、运行时或基础资源时失败。
- [ ] **Step 5: 提交**：`git add packaging licenses tests/packaging && git commit -m "build: package GPL desktop runtime"`。

### Task 2: 性能场景与基准采集

**Files:** Create `tests/perf/run_benchmark.cpp`, `tests/perf/results/.gitkeep`, `docs/operations/performance-report-template.md`.

**Consumes:** 00 的性能合同、G-03 的固定硬件与已校验 SHA-256 的素材夹具。

**Produces:** 可复验的 JSON/Markdown 性能报告；不满足门槛时明确失败而非降低夹具。

- [x] **Step 1: 写失败测试**:

```cpp
void test_EmitsAllRequiredMetrics() { QVERIFY(report.has("peak_rss_mb") && report.has("seek_p95_ms")); }
```

- [x] **Step 2: 验证失败**：运行 `ctest --preset macos-debug -R performance.metrics --output-on-failure`，预期失败。
- [ ] **Step 3: 最小实现**：执行 00 合同中的素材与场景，每个场景固定运行 5 次，采集中位数/p95 的冷启动、导入、首帧、拖拽、预览 seek、峰值 RSS、GPU、代理、H.264/HEVC/ProRes 导出速度和输出 SSIM；夹具必须校验 SHA-256。Windows 固定 i5-10 代/16 GB/GTX1030；macOS 固定 M1 Air/8 GB。
- [ ] **Step 4: 验证通过**：重跑测试，预期报告包含机器、依赖版本、场景哈希、指标和失败原因。
- [ ] **Step 5: 提交**：`git add tests/perf docs/operations && git commit -m "test: add release performance benchmarks"`。

### Task 3: 双平台安装验收与升级策略

**Files:** Create `docs/operations/release-checklist.md`, `docs/operations/macos-install-smoke.md`, `docs/operations/windows-install-smoke.md`, `tests/packaging/test_smoke_install.cpp`.

**Consumes:** Task 1 的安装包、Task 2 的性能报告、G-04 的 Windows 目标机。

**Produces:** macOS/Windows 逐项安装验收记录和可发布/不可发布结论。

- [ ] **Step 1: 写失败测试**:

```cpp

```

- [ ] **Step 2: 验证失败**：运行 `ctest --preset macos-debug -R packaging.install_smoke --output-on-failure`，预期失败。
- [ ] **Step 3: 最小实现**：定义安装、首启、创建、导入、预览、十分钟保存模拟、关闭重开、普通 MP4、透明 MOV、资源目录签名失败和插件签名失败的双平台检查；升级固定旧资源版本并提示升级。
- [ ] **Step 4: 验证通过**：重跑测试，预期两平台清单全部通过后才可发布。
- [ ] **Step 5: 提交**：`git add docs/operations tests/packaging && git commit -m "docs: add cross-platform release gate"`。

## 验收门

不以未测试的硬件编码器、缺少 GPL 通知、缺失资源或降低性能夹具负载换取发布通过。
