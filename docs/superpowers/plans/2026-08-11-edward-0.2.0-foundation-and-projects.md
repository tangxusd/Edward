# Edward 0.2.0 基础、工程与创建流程实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` task-by-task. Steps use checkbox syntax.

**Goal:** 从空代码库创建跨平台 C++20 工程，交付版本化工程保存、受管媒体导入、首页历史工程和新建项目入口。

**Architecture:** `edward_core` 不依赖 Qt 与媒体库，持有 `ProjectDocument`；`edward_media` 只探测与复制受管媒体；桌面控制器只把文件选择结果转为明确命令。持久化严格遵从 00 模块 Schema。

**Tech Stack:** C++20、CMake、CTest、Qt6/QtTest/QML、GPL FFmpeg/FFprobe、nlohmann/json。

## Global Constraints

- 所有路径写入工程时必须相对工程根目录；源文件仅复制，不移动或删除。
- 每十分钟完整保存；关闭与导出前的强制保存由后续控制器调用同一 `ProjectStore::saveFull`。
- 文稿可选；支持 TXT、Markdown、DOCX、可复制文本 PDF、SRT；扫描 PDF 不做 OCR。
- 新建工程只使用文稿或本地转写文本做语义输入，不抽取视频关键帧。

## 自审

- 覆盖 CMake、工程真相、受管导入、首页、创建和删除隔离；不实现时间线、AI、资源、预览或导出。
- 所有后续模块只通过公开 C++ 接口消费本模块，禁止直接读写 `project.json`。
