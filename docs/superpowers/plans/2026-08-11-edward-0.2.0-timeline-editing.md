# Edward 0.2.0 时间线与编辑命令实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` task-by-task. 每项完成前先通过指定的单一 CTest，再进入下一项。

**Goal:** 实现单主时间线、V1–V10/A1–A10、剪映兼容编辑命令、播放头、入出点、标记和五步历史。

**Architecture:** `Timeline` 只处理不可变帧和片段状态；所有用户编辑封装为可逆 `EditCommand`；QML 只把鼠标/快捷键映射为控制器命令。完整路径和跨层接口以 `docs/contracts/implementation-file-ownership.md` 为准。

**Tech Stack:** C++20、QtTest、Qt/QML。所有测试遵从 `docs/contracts/testing.md`。
