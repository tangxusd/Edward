# Edward 0.3.1 导出面板实施计划

## 目标

将当前固定 MP4 文件选择导出替换为已确认视觉稿要求的真实导出面板：文件名、输出位置、分辨率、帧率、格式、质量与进度均有明确状态；预览和导出继续复用同一 RenderGraph。

## 边界与假设

- 普通成片第一步只开放现有已验证的 MP4/H.264 路径；透明 ProRes 4444 是独立交付格式，不得伪装成普通 MP4。
- 分辨率、帧率与质量参数必须传入导出任务，不能只改变 UI 文案。
- 取消、失败和成功都不得删除已有输出文件。
- 不改变系统原生标题栏或已确认的工作台布局。
