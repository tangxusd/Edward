# Edward 0.2.0 AI、模型与插件实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` task-by-task.

**Goal:** 实现多模型接入、创建时语义初版、组件级 AI 合并、全局 AI 创作和受限插件边界。

**Tech Stack:** C++20、QtTest/CTest、nlohmann/json、Qt Network、libsodium Ed25519 验签、whisper.cpp、libzip/pugixml/Poppler。测试必须遵从 `docs/contracts/testing.md`；网络、文稿、转写与插件边界必须遵从 `docs/contracts/dependency-lock.md`、`docs/contracts/local-transcription-and-document-import.md`、`docs/contracts/plugin-host-rpc.md`。

## 验收门

用户界面不显示审核/上传提示；插件无网络直连、无工程写权限；AI 结果未点击应用前不可修改时间线；价格、设备和订阅状态不能伪造成功。
