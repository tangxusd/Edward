# Edward 0.2.0 导出与硬件编解码实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` task-by-task.

**Goal:** 用统一 RenderGraph 导出 MP4 H.264/HEVC 与透明 ProRes 4444，支持质量档、硬件优先和可靠取消。

**Global Contract:** 导出参数以台账第 16 节为精确来源：H.264 为 CRF 22/19/17，HEVC 为 26/23/20，AAC 48 kHz/320 kbps，ProRes 为 `prores_ks`/`yuva444p10le`/PCM 48 kHz 24-bit；24/25 fps 转换，50/60 fps 仅重复帧；色彩转换失败阻止导出；硬件后端只有实测达到同档质量语义才可用。
