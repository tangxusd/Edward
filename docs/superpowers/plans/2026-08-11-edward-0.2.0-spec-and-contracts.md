# Edward 0.2.0 规格与核心合同实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` task-by-task. Steps use checkbox syntax.

**Goal:** 在任何应用代码前冻结工程、媒体、渲染与性能合同，使后续模块不依赖口头推断。

**Architecture:** 用版本化 JSON Schema 描述工程真相；用 C++ 头文件描述跨模块不可变快照；用固定夹具描述预览、导出和性能验收输入。

**Tech Stack:** JSON Schema Draft 2020-12、C++20、QtTest、CTest、FFprobe、MLT。所有测试必须遵从 `docs/contracts/testing.md`；所有依赖必须遵从 `docs/contracts/dependency-lock.md`。

## Global Constraints

- 单时间线、30 fps、48 kHz、Rec.709 SDR；项目内仅保存受管副本和剪辑决定。
- 十分钟完整保存、关闭/导出强制保存、五步命令历史；缓存永不进入工程 JSON。
- `media/` 只保存原始字节副本；RenderGraph 依据探测元数据非破坏性转换到 Rec.709，代理可为派生文件；失败必须成为用户可见错误。
- 全部组件、字幕、转场、关键帧和缺失占位由同一 RenderGraph 求值。

- [ ] **Step 4: 运行并确认通过**

```sh

```
