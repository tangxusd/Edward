# Edward 0.1.1 Full Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the confirmed Edward 0.1.1 macOS/Windows desktop editor, with working project flow, timeline editing, AI-assisted components, export and local settings.

**Architecture:** Keep Electron main-process services for files, projects, models and FFmpeg; keep React renderer components focused on individual panels. Persist project state and resources locally; expose future subscription, component-sync and administrator review as typed IPC/service boundaries without shipping their external backend.

**Tech Stack:** Electron 37, electron-vite, React 19, TypeScript, Vitest, Playwright, FFmpeg, existing workspace packages.

## Global Constraints

- Product name `Edward`, desktop package version `0.1.1`.
- Preserve confirmed deep-dark compact UI and system-native window controls.
- Use system file picker for media import; do not add an app-level media-import dialog.
- Keep AI writes behind user-facing apply actions; never overwrite source analysis.
- Trial/payment/device/admin backends are not implemented in this client phase.

---

## File Structure

- `apps/desktop/src/renderer/main.tsx`: application route/state shell.
- `apps/desktop/src/renderer/{HomePage,Workbench,RightInspector,GlobalAiCreate}.tsx`: page-level renderer units.
- `apps/desktop/src/renderer/{Timeline,PreviewCanvas,LibraryPanel}.tsx`: editing interactions.
- `apps/desktop/src/main/{projectRepository,workspace,exportService,componentSyncService}.ts`: persisted data and IPC services.
- `apps/desktop/src/shared/ipc.ts`: shared IPC contracts.
- `apps/desktop/unit/*.test.ts`, `apps/desktop/tests/smoke.spec.ts`: unit and workflow coverage.
