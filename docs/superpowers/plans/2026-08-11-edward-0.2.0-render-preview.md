# Edward 0.2.0 RenderGraph、预览与参考线实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` task-by-task.

**Goal:** 用 MLT 以单一 RenderGraph 实现实时预览、代理、缺失占位、标尺、吸附和参考线。

### Task 1: RenderGraph 与 MLT 适配

**Files:** Create `src/media/include/edward/media/render_graph.hpp`, `src/media/src/render_graph.cpp`, `src/media/include/edward/media/mlt_adapter.hpp`, `src/media/src/mlt_adapter.cpp`, `tests/media/test_render_graph.cpp`, `tests/media/test_mlt_adapter.cpp`.

**Consumes:** 00 的 RenderGraph 合同、02 的 Timeline、03 的组件/关键帧快照。

**Produces:** `RenderGraph::build(const ProjectSnapshot&, const RenderRequest&) -> RenderScene`、`MltAdapter::buildProducer(const RenderScene&)`。

- [ ] **Step 1: 写失败测试**:

```cpp
void test_MissingAssetBuildsPlaceholderLayer() { QCOMPARE(graph.layerFor(missing).kind, LayerKind::Placeholder); }
void test_ExportNeverUsesProxy() { QVERIFY(!graph.forExport().usesProxy()); }
```

- [ ] **Step 2: 验证失败**：运行 `ctest --preset macos-debug -R media.render_graph --output-on-failure`，预期失败。
- [ ] **Step 3: 最小实现**：实现从不可变 `ProjectSnapshot` 生成 MLT producer/filter/tractor；按时间线层级合成，统一求值字幕、组件、关键帧、转场、黑边、混音和 Rec.709。MLT 只能接收已求值 `RenderScene`，不得改变核心状态。
- [ ] **Step 4: 验证通过**：重跑测试，预期缺失层、原画导出、帧层级和相同帧预览/离屏场景一致通过。
- [ ] **Step 5: 提交**：`git add src/media tests/media && git commit -m "feat: add unified render graph"`。

## 验收门
