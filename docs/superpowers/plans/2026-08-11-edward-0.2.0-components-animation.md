# Edward 0.2.0 组件、属性与动画实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` task-by-task.

**Goal:** 建立模板到独立实例、文字/图表内容编辑、关键帧曲线和默认入场动画。

**Architecture:** 模板不可变；添加到时间线时深拷贝为 `ComponentInstance`；属性与节点关键帧统一存入 `KeyframeTrack<T>`。

### Task 1: 模板、实例与节点选择

**Files:** Create `src/core/include/edward/core/component_template.hpp`, `src/core/src/component_template.cpp`, `src/core/include/edward/core/component_instance.hpp`, `src/core/src/component_instance.cpp`, `tests/core/test_component_instance.cpp`.

**Consumes:** 02 的 `Clip`、`FrameRange`、强类型 ID。

**Produces:** 不可变 `ComponentTemplate::instantiate(ComponentId)`、`ComponentInstance::clone()`、`removeNode(NodeId)`、`replaceTemplate(const ComponentTemplate&)`。

- [ ] **Step 1: 写失败测试**:

```cpp
void test_CloneDoesNotShareNodes() { auto b=a.clone(); b.removeNode(text); QVERIFY(a.hasNode(text)); }
void test_RemovingNodeKeepsContainer() { instance.removeNode(node); QVERIFY(instance.containerExists()); }
```

- [ ] **Step 2: 验证失败**：运行 `ctest --preset macos-debug -R core.component_instance --output-on-failure`，预期失败。
- [ ] **Step 3: 最小实现**：实现只读模板、独立实例、容器变换与文字/数据节点；图表数据以表格字段，卡片内部文字必须在预览另选后编辑。
- [ ] **Step 4: 验证通过**：重跑测试，预期模板不变、实例隔离、节点删除保留容器。
- [ ] **Step 5: 提交**：`git add src/core tests/core && git commit -m "feat: add component instances"`。

### Task 2: 关键帧与贝塞尔求值

**Files:** Create `src/core/include/edward/core/keyframes.hpp`, `src/core/src/keyframes.cpp`, `tests/core/test_keyframes.cpp`.

**Consumes:** Task 1 的独立组件实例和 02 的 `Frame`。

**Produces:** `KeyframeTrack<T>::set(Frame, T, Interpolation)`、`remove(Frame)`、`evaluate(Frame)`，其中 `Interpolation` 只为保持、线性、时间三次 Bézier、位置空间 Bézier。

- [ ] **Step 1: 写失败测试**:

```cpp
void test_EvaluatesCubicBezierAtPlayhead() { QVERIFY(qAbs(track.evaluate(15).x - 42.0) < .01); }
void test_HidesOutOfRangeKeysUntilClipExtends() { QVERIFY(!track.isActiveAt(120)); }
```

- [ ] **Step 2: 验证失败**：运行 `ctest --preset macos-debug -R core.keyframes --output-on-failure`，预期失败。
- [ ] **Step 3: 最小实现**：实现位置、缩放、旋转、不透明度、颜色、图表圆角/间距、音量的保持/线性/三次 Bézier；每个参数独立菱形状态；比例锁定只影响 X/Y 缩放联动。
- [ ] **Step 4: 验证通过**：重跑测试，预期数值、范围、独立属性和缩短组件后超范围关键帧不播放通过。
- [ ] **Step 5: 提交**：`git add src/core tests/core && git commit -m "feat: add keyframe curves"`。

### Task 3: 预设动画与属性控制器

**Files:** Create `src/core/include/edward/core/animation_presets.hpp`, `src/core/src/animation_presets.cpp`, `src/desktop/include/edward/desktop/property_controller.hpp`, `src/desktop/src/property_controller.cpp`, `tests/core/test_animation_presets.cpp`, `tests/desktop/test_property_controller.cpp`.

**Consumes:** Task 1–2 的实例和关键帧接口。

**Produces:** `applyPreset(AnimationPreset, ComponentInstance&, FrameRange)`、文字/图表/字幕属性控制器和关键帧写入命令。

- [ ] **Step 1: 写失败测试**:

- [ ] **Step 2: 验证失败**：运行 `ctest --preset macos-debug -R core.animation_presets --output-on-failure`，预期失败。
- [ ] **Step 3: 最小实现**：实现淡入、缩小、放大、轻微放大、上下左右滑动；默认 0.4 秒缓出，每个预设只覆写受影响属性和应用范围。控制器提供字幕统一样式、图表双击编辑/失焦确认、卡片文字另选后编辑及同类型替换保留容器变换与关键帧。
- [ ] **Step 4: 验证通过**：重跑核心和桌面测试，预期预设范围、属性覆盖、表格失焦确认和字幕统一样式正确。

## 验收门

任何时间线实例的修改不得回写资源模板或其他实例；所有文字节点均可编辑；关键帧以播放头时间写入。
