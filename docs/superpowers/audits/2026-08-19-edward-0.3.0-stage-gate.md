# Edward 0.3.0 基础剪辑 MVP 阶段门

**审计日期：** 2026-08-19（Asia/Shanghai）

## 结论

基础剪辑 MVP 的本机验收门通过。它覆盖导入单段视频、播放头分割、波纹删除、组件叠加、预览合成和 1920×1080 H.264 导出。

## 可执行验证

| 项目 | 结果 | 证据 |
| --- | --- | --- |
| 时间线编辑 | 通过 | `e2e.edward_0_3_0_smoke` 导入夹具后在第 10 帧分割并波纹删除，保留有效片段。 |
| 预览合成 | 通过 | 端到端测试将红色标准组件叠加到素材帧并检查中心像素。 |

| 完整测试 | 通过 | `cmake --preset macos-debug`、`cmake --build --preset macos-debug -j2` 与 `ctest --preset macos-debug --output-on-failure`，26/26 通过。 |

## 已知边界

- 这是基础剪辑 MVP，不代表多轨音频、波形、调色或完整 Shotcut 功能已验收。
- Windows 打包与运行验证仍待 GitHub/Windows 环境完成，不能用 macOS 结果替代。
- macOS 本机仅完成 `.app` 构建；按当前交付决定，不验证 DMG。
- 外部插件目前是受控子进程，但尚未实现 macOS/Windows OS 级沙盒、插件签名或公钥信任根。
- 发行级签名与 Windows MSI 验证尚未完成，不能将本机阶段门误作正式发布验收。
