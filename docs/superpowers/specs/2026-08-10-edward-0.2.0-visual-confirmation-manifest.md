# Edward 0.2.0 视觉确认稿清单

## 用途与效力

本文件冻结 Edward（剪刀手）0.2.0 的视觉入口。实施者只能将本文件列出的 HTML 当作页面布局、控件位置、层级和视觉密度的输入；不能从同目录中较早版本推断或补回已被用户否决的布局。

功能、数据、引擎、性能、持久化和安全边界以 [0.2.0 需求审计台账](../../operation-log/2026-08-10-001-requirement-audit.md) 为准。发生冲突时，台账优先；视觉稿只约束页面入口和交互呈现。

所有路径相对项目根目录。未列在本文件中的 HTML 均为过程稿、局部状态稿或被后续版本取代，不得作为最终页面实现依据。

## 全局规则

- 所有页面使用深色专业剪辑台视觉；不使用 Emoji，使用 SF 图标或等义系统图标。
- macOS 保留原生红黄绿窗口控制；Windows 保留原生最小化、还原/最大化、关闭；不设置应用内仿制标题栏，双击系统标题栏必须维持原生缩放。
- 首页是创建项目和切换历史项目的唯一入口；工作台内不得提供新建、最近项目或切换项目目录。
- 工作台所需项目名称、保存状态、模型状态、设置和导出入口只能在系统标题栏安全区域呈现；不建立第二条内容区标题栏。
- 资源库八个一级 Tab（媒体、文本、音频、卡片、图表、背景、标注、数字）统一使用共享的资源 Tab 样式与 SVG 图标：图标置于文字上方，固定 18×18、1:1 可见区域、浅灰细线；选中项图标与文字均为青色。带外框图标使用同尺寸正方形圆角外框；音频、卡片、标注不额外加外框；数字使用已确认的填充“123 + 上下横线”图形。
- 除媒体外的文本、音频、卡片、图表、背景、标注、数字 Tab，分类栏固定将“我的”置于最上方，“默认”置于其下；媒体 Tab 保持“导入素材 / 我的 / AI 生成”的已确认结构。
- 所有“锁定宽高比”控件统一使用链条 SVG：锁定为青色，解除锁定为灰色；点击切换状态，不再使用文字或其他图标代替。
