# Edward 0.1.1 已确认界面方案

## 范围与冻结规则

- 软件名称为 Edward，版本为 0.1.1；视觉为紧凑的深色专业剪辑台风格。
- 已确认页面的内容、布局与控件不再自行改动；后续只接受用户明确的变更。
- 所有顶层窗口保留系统原生窗口控制：macOS 的关闭/最小化/最大化，Windows 的最小化/最大化/关闭；不挤占内容区。
- 首页是唯一的新建、打开历史项目与切换项目入口。进入工作台后不得切换项目，必须关闭项目返回首页。

## 首页与账户

- 首页：左侧满高广告预留列，列底部为“资源库升级”；主体为搜索、历史项目卡片与新建项目；右上仅有设置和账户头像。
- 新建项目：必须选择一条音频或视频主媒体；文案文稿可选，未提供时使用本地转写文本。支持常见文档文本格式。
- 登录、注册、CD-KEY 和充值由账户入口进入。注册必须先通过图形验证码，再发送短信或邮箱验证码；免费试用期为首次激活后 3 天。
- 订阅提供月、季、年付；订阅只售卖软件使用权，不含云端模型额度。最多绑定 3 台设备，同时只允许 1 台活动使用；提供设备停用与新设备激活。

## 设置、模型与资源升级

- 设置为独立面板，包含“项目设置”和“大模型设置”。
- 项目设置：项目默认位置、资源位置、预览清晰度（原画/清晰/流畅）、代理位置、缓存位置、渲染位置。清晰/流畅生成代理，导出仍使用原画或导出指定质量。
- 资源位置行只新增“资源库升级”按钮，其余设置项和布局保持不变。
- 大模型列表支持使用、测试、编辑、删除。添加模型支持配置模板（含自定义）、接口地址、模型标识、API Key、上游协议（Responses API / Chat Completions）以及从上游拉取模型。
- 资源库升级面板分类为：文本、音效、卡片、图表、背景、标注、数字。支持分类升级、单资源升级、预览放大和动画演示。标注包含框选、引出标注、箭头等；数字包含百分比、数字标题和计数器。

## 项目工作台

- 顶栏左侧为 Edward 与保存状态，中部固定项目名称，右侧为默认模型名与在线/离线状态及唯一的导出入口。
- 左栏 Tab：媒体、文本、音频、卡片、图表、背景、标注、数字。
- 媒体导入直接调用系统文件选择器；支持格式立即导入，格式不支持或解析失败则显示原因；不使用应用内导入弹窗。
- 文本支持新建并拖入时间线。音频、卡片、图表、背景、标注、数字均从资源库拖入时间线。资源卡片采用紧凑样式，带收藏、添加以及小型删除按钮；音效为三列紧凑卡片，时长与收藏/添加同一行。
- 中栏预览窗位置锁定，组件可选择、拖拽、缩放与吸附。预览窗右上有参考线菜单；画布顶部与左侧使用密集主/次刻度标尺。底部同一控制条显示时间码、播放/暂停及画幅/预览清晰度。
- 分栏：左/中分隔线只存在于上部工作区；中/右分隔线贯穿全高；上/下分隔线只分隔左中区域，右栏完整到底。分隔线可拖拽调整区域大小。
- 时间线仅显示剪映式时间标尺与播放头，不显示工具栏按钮；轨道头仅显示 V3、V2、V1、A1。视频轨从 V1 向上递增，音频轨从 A1 向下递增。播放头（定位轴）是所有工作台状态的常驻功能，用于确定关键帧的起止时间。
- 右栏上半为属性区。选择文字显示文字属性；选择卡片、图表、素材显示组件属性。字幕支持“统一修改”样式。每个可动画参数末尾独立显示关键帧菱形：实心为当前定位轴时间点已激活，空心为未激活；多个参数可组合出复杂动画。
- 文字属性包含可直接编辑的内容、系统与内置字体、字号、颜色、左/中/右对齐、位置、X/Y 缩放、不透明度、文字背景、阴影和入场动画。选择字幕时显示“统一修改所有字幕样式”；选择普通文字时不显示该选项。文字不显示 AI 对话区。
- 组件导入时必须声明“锁定样式”和“可修改字段”。锁定样式不对用户开放编辑，仅可因内容变化自动调整宽高；工作台通用的时间线位置、缩放和动画不属于资源内部样式。卡片的内部可修改字段仅为文字内容；图表的可修改内容以数据表呈现，可修改样式以属性区呈现。
- 图表属性包含：X/Y 百分比缩放及默认启用的等比锁定、位置、旋转、不透明度、入场动画下拉选择、关键帧、可编辑的数据表格，以及图表外观。图表外观包含系列颜色、柱形圆角、柱间距、组间距、坐标轴、标签、刻度及网格线；颜色、圆角和间距可设关键帧，坐标轴与网格线为图表全局样式。数据表双击单元格进入编辑，点击表格外后显示变更摘要，由用户确认修改或撤销。
- 右栏下半在选中卡片或图表时显示 AI 对话区，贴右下对齐，占右栏约一半高度；包含独立组件会话历史、右上模型下拉、默认四行且可调高度的输入框、叠放在输入框左上角的圆形文件导入按钮。AI 返回的数据须经格式比较/合并并由用户点击应用后才写入组件。
- 未选中任何组件时，右栏仅显示占满高度的“全局 AI 创作”对话，不显示属性区。用户可导入截图或视频，让 AI 生成组件草稿；草稿可预览并应用到时间线，或保存到组件库。保存后组件默认静默同步到服务器，供管理员后续审核并决定是否发布到公开资源库；用户界面不显示同步、审核或提交确认。
- 选择卡片、图表时显示组件级 AI 对话；选择文字、主媒体、音频、背景、标注、数字或未选中时不显示组件级 AI 对话。无 AI 对话时，右栏属性区延展占满高度，不保留空白。卡片属性页只显示组件通用变换、入场动画与关键帧；卡片内文字须在预览窗中单独选中后进入文字属性面板修改。
- 主视频与背景默认按画布比例铺满全屏。背景、标注、数字均仅显示通用变换、入场动画与关键帧；标注与数字的资源内部样式锁定。
- 时间线素材两端均提供裁剪手柄，以拖拽改变时长；素材可拖拽跨轨道改变堆叠顺序。拖至已有轨道外时自动新增对应的视频或音频轨道。
- 参考线菜单为紧凑宽度，仅容纳菜单文字与状态标记；画幅与预览清晰度菜单以彩色状态点表示当前选择。

## 生成、导出与项目操作

- 创建项目后显示本地媒体读取、本地转写、云端语义分析与多轨时间线生成的阶段进度；取消不删除项目与素材。
- AI 方案应用面板展示方案摘要和时间片段；AI 原始结果保留，用户确认后应用到时间线。
- 导出面板包含项目名默认文件名、按横竖画幅自动识别的分辨率、帧率、格式、导出位置和真实进度。导出手动触发。
- 关闭项目必须确认；项目已保存后返回首页。
