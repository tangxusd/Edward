# 组件 AI 对话修改设计

## 目标

用户选中预览画布中的卡片、图形或字幕后，右侧检查器除属性面板外显示组件级 AI 对话。AI 收集和整理组件数据，生成内容修改草案；只有用户点击应用后才修改组件内容。

## 范围

- 卡片、图形和字幕显示“AI 修改组件”面板；背景资源不显示该面板。
- 面板内可选择任一已配置的云端模型。
- AI 请求携带项目文稿上下文、当前组件类型、当前 `content` 和对话历史。
- AI 返回自然语言回复与候选 `content` JSON 补丁。
- 用户点击“应用修改”后，仅替换当前片段的 `content`；位置、尺寸、缩放、时长、样式和资源 ID 保持不变。
- AI 调用前沿用现有授权校验边界。

## 对话保存

对话以片段 ID 为键保存到工程。每个组件最多保留一个非空对话：首次选中且没有历史时显示空状态，不写入工程；成功完成至少一轮用户消息和 AI 回复后才写入该组件的会话。切换组件时加载该组件的会话，不与其他组件混合。

每条会话保存所用模型 ID、用户消息、AI 回复、最新候选 `content` 和更新时间。候选内容仅在用户点击应用时写入时间线片段。

## 格式保护

发送前向 AI 提供当前组件内容格式。接收草案后，应用以当前内容为基准递归合并：未提供的字段保持原值；草案字段必须已存在且类型一致；非空数组按元素递归校验和合并，草案可改变数组长度但不能引入未知字段或不兼容类型。根类型、字段类型、数组元素类型不兼容或未知字段都会拒绝应用，并在右栏显示原因。只有合并校验通过的草案才可点击应用。

## 交互

1. 用户选中一个可编辑组件。
2. 右侧显示属性、同类资源和 AI 对话面板。
3. 用户选择模型并输入修改意图，例如“将折线图改为最近四季度收入”。
4. 应用将上下文发送给云端模型，显示 AI 回复和待应用草案。
5. 用户点击“应用修改”，组件立即更新；操作进入撤销/重做、自动保存和项目持久化。

## 错误处理

- 未配置模型、空消息、请求中或没有候选草案时，发送或应用按钮不可用。
- 模型返回的候选内容不是合法 JSON 时，不写入会话或工程，并显示错误。
- 请求失败时保留此前已保存的会话与当前工程，不修改组件。

## 验证

- 选中卡片、图形和字幕可见 AI 对话面板，背景不可见。
- 面板可切换模型，发送后持久化该组件的非空会话。
- 未点击应用前，候选草案不改变组件内容。
- 点击应用后，仅组件内容改变，布局、时长和样式不变，并可撤销。
- 重开工程后，对话历史与待应用草案仍与对应组件关联。
