# Edward 0.2.0 权威规格与需求追溯矩阵

本文件把需求审计台账、最终视觉确认稿与模块计划连接为唯一可执行输入。它不改变任何已确认决定；发生冲突时优先级为：**本文件引用的较新台账决定 > 视觉清单的不可变视觉规则 > 模块计划的实现细节**。旧 Electron/React/TypeScript/Python 代码和未列入视觉清单的 HTML 不能作为实现来源。

## 1. 产品和架构不变量

## 9. 失败/离线与验收规则

- 不可用模型、转写失败、语义失败、schema 不匹配、AI 超时、缺失媒体/资源、资源/插件签名失败、不可用硬件编码、色彩转换失败、订阅验证失败与磁盘阈值均必须有确定错误状态和测试。
- 后端服务不存在或不可访问时，客户端只能显示真实失败/离线，不能显示成功、完成下载、已支付、已审核或已登录。
- 每个 ID 的测试在 QtTest/CTest 中注册；性能和安装包验收在两台确认机器上实测，比较对象是剪映 11.0.0。
- 本文件的任务编号在模块计划改动时必须同步更新；任何未映射的新需求禁止进入实现。
