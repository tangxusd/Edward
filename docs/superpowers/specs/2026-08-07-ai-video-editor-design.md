# AI 剪视频工具设计

## 目标

构建一个兼容 macOS 与 Windows 的桌面 AI 剪视频工具。用户提供一份文案或文稿，以及一条音频或视频主媒体；应用在本地完成转写和时间戳对齐，调用用户配置的云端大模型完成语义分析，自动生成可人工调整的多轨时间线。

第一版定位为“AI 生成剪辑工程 + 人工确认与微调”，不是从空白时间线开始的全功能专业 NLE。

## 成功标准

- 用户可创建和管理多个项目，并设置统一的项目工作目录。
- 新建项目必须同时选择一条音频或视频，以及一份文案或文稿。
- 本地转写生成可编辑的逐句时间戳字幕；原始媒体不上传。
- 云端模型只收到文稿、转写内容和时间戳，返回受校验的语义剪辑计划。
- 应用可自动生成主媒体、背景、字幕、卡片和图形等多轨时间线；用户可手动修订。
- 用户可导入、分类、预览和收藏背景、卡片、时间轴、曲线图与完整风格包。
- 用户手动选择导出目录、画幅、分辨率和质量，查看 FFmpeg 实时导出进度并可取消。
- 普通视频导出为 MP4/HEVC/AAC；透明导出为 MOV/ProRes 4444，必须通过 macOS 与 Windows 剪映实测后才能标记兼容。
- 软件订阅支持 7 天试用、月/季/年付费、最多三台绑定设备、单一活动会话和两小时离线编辑窗口。

## 非目标

- 第一版不实现多机位、调色、混音台、关键帧动画系统或复杂转场。
- 第一版不内置或代付云端大模型额度；用户自行配置模型服务。
- 用户不能从编辑器把当前页面保存为资源库条目；资源库只能通过受校验的导入包新增。
- 不自动导出视频；所有导出由用户主动触发。

## 技术架构

采用 Electron、React、TypeScript、本地 Python 任务与 FFmpeg 子进程。

| 层级 | 职责 |
| --- | --- |
| Electron 主进程 | 窗口、文件系统、项目读写、本地凭证文件、任务调度与授权会话 |
| React 渲染进程 | 项目启动页、编辑工作台、预览、时间线、资源库、设置与导出面板 |
| 本地媒体层 | Python faster-whisper 转写和对齐；FFmpeg 读取媒体、生成波形及导出 |
| AI 编排层 | 调用所选云端模型记录，校验结构化剪辑计划并应用到工程 |
| 授权服务 | 账户、订阅、试用、设备绑定、单一活动会话与授权令牌 |

Electron 选择的原因是可复用现有 HTML/JavaScript 预览编辑思路，并以成熟的跨平台文件、密钥和媒体子进程能力承载本地模型与 FFmpeg。代价是安装包体积高于 Tauri，但不缩减需求。

## 工作目录与多项目

用户设置一个工作目录，应用在该目录中维护项目、资源库、缓存和默认导出目录。

```text
工作目录/
├── projects/
│   └── <project-id>/
│       ├── project.json
│       ├── media/
│       ├── transcripts/
│       ├── ai-plans/
│       ├── previews/
│       └── exports/
├── library/
│   ├── backgrounds/
│   ├── card-styles/
│   ├── timeline-styles/
│   ├── charts/
│   └── index.json
└── cache/
```

启动页只展示新建项目与历史项目。创建或打开项目后进入剪辑工作台；在关闭当前项目之前不能切换项目。工作目录和云端模型在独立设置弹窗中配置，不出现在启动页或编辑器侧栏。每个项目独立保存媒体引用、转写、AI 计划、时间线人工修订、样式快照和最近导出设置。资源库由工作目录共享；项目使用资源 ID，同时保留应用时的样式快照，避免资源库后续修改改变旧工程。

项目媒体路径失效时，应用列出待修复媒体并允许用户重新定位。

## 项目和时间线数据

`project.json` 保存项目元数据、画幅、媒体引用、轨道、片段、样式快照和导出设置；不保存 API Key、授权状态或设备标识。

第一版时间线有以下轨道：

- 主媒体轨：用户导入的一条音频或视频。
- 背景轨：视频项目可使用背景资源；纯音频项目自动铺设资源库中的默认背景图，可手动替换。
- 字幕轨：本地转写生成，可直接修改文本和时间。
- 语义卡片轨：关键词、标题、说明文字和强调信息。
- 图形轨：时间轴、曲线图和数据图等图形组件。

每个片段至少保存 `start`、`duration`、`sourceRange`、`content`、`styleId`、`locked` 和可选的画布布局 `{ x, y, width, height }`。时间线支持添加、替换、删除、复制、拖拽移动和拖拽左右边缘调整时长，所有变更实时同步到预览。

AI 原始分析结果保持只读。用户编辑创建当前剪辑版本，能够修改关键词、换行、字体、时间、资源和片段内容。重新运行 AI 后，用户可选择只覆盖未修改片段、只应用新增片段或丢弃本次结果。

## 字幕与文本编辑

字幕轨支持统一设置字体、字号、颜色和文字背景，也支持单条字幕局部覆盖。文本属性的应用范围为当前元素、当前轨道、当前页面或全项目，局部设置优先于全局设置。

预览中选中资源外框时，右侧栏显示同类资源库内容和预览图；选中文字时，右侧栏切换为文字内容、换行、字体、字号、颜色、文字背景和应用范围。卡片、背景、时间轴和曲线图均遵循这一选择和替换方式。

预览画布支持直接拖拽组件位置和八向控制点缩放。缩放默认锁定宽高比，按住 `Shift` 才允许自由改变宽高。拖拽时显示画布的水平、垂直中心参考线，以及其他组件的边缘和中心参考线；组件进入吸附阈值时自动对齐。双卡和三卡布局还提供顶部、垂直中心、底部和等间距参考线。用户拖动其中一个同布局组件后，应用根据可用画布宽高重新推算其余组件的位置与均匀间距；手动布局的组件只吸附，不自动移动其他组件。

## 资源与样式库

资源库包含背景图、卡片风格、时间轴风格、曲线图风格和完整风格包。每个资源保存唯一 ID、类型、名称、分类、缩略图、收藏状态、风格参数、文件哈希和更新时间。

新增资源只能通过设置页导入受校验的素材包或风格包。风格包格式限定为 ZIP、JSON、CSS 和静态媒体，不允许可执行脚本。资源库支持分类、搜索、收藏、预览、删除和重新分类；背景显示缩略图与原图，其他样式以 16:9 或 9:16 画布预览。

## 本地转写和云端语义分析

处理步骤：

1. 用户导入文稿和主媒体。
2. 应用读取媒体时长、帧率、采样率和画面尺寸。
3. 本地 faster-whisper 对音频转写；视频仅在本地提取音频。
4. 应用将文稿、转写内容与时间戳发送给当前云端模型记录。
5. 模型返回结构化剪辑计划：语义段落、拍点、关键词、副文、字幕分组、组件类型、资源类型/ID、时间、持续时间、布局与样式。
6. 应用校验时间顺序、媒体边界、资源存在性、关键词和字幕时间；通过后生成初版多轨时间线。
7. 用户人工修订或选择性应用后续 AI 分析结果。

模型记录支持名称、OpenAI 兼容 API 地址、模型标识和凭证引用。API Key 保存于本地应用数据目录的凭证文件，不写入工程和资源包。顶部显示当前模型名称和连接状态：在线为绿色，离线或不可用为红色。

失败时的行为：

- 本地转写失败：保留项目和媒体，可查看错误并重试。
- 云端请求超时或结构非法：不改动现有时间线，保留响应诊断信息。
- 资源缺失：生成待修复占位片段。
- 网络中断或订阅失效：不启动 AI 任务，保留本地工程编辑。

## 编辑界面

启动页包括新建项目和历史项目。订阅与设备管理后续在外部服务方案明确后开发，不作为当前启动页入口。

新建项目弹窗要求添加音频或视频与文案/文稿，两个输入都完成后才能创建项目并开始转写和语义分析。

剪辑工作台包括：

- 顶部：项目名、保存状态、撤销/重做、当前模型名和状态、关闭项目、设置和手动导出。
- 左侧：资源库，支持导入风格包、分类、搜索、收藏与资源预览。
- 中央：16:9 或 9:16 预览画布。
- 底部：多轨时间线与轨道管理；主媒体在最下层，背景、字幕、卡片和图形依次向上排列。
- 右侧：所选资源的同类资源预览，或所选文本的属性面板。

设置弹窗只包含工作目录和 AI 模型两个分类。画幅、分辨率、质量、透明通道和输出目录只在手动导出面板中选择。

## 导出

导出由用户手动触发。导出面板提供：

- 画幅：默认 16:9，可选 9:16。
- 分辨率：720p、1080p、1440p、4K 和自定义宽高。
- 质量：高质量、均衡、紧凑。
- 背景：普通或透明。
- 输出：用户选择目录和文件名。

FFmpeg 输出时显示当前阶段、已完成帧数、百分比、编码速度和预计剩余时间。用户可取消；取消时清理未完成文件且不改动工程。

普通导出使用 MP4/HEVC/AAC。透明导出使用 MOV/ProRes 4444。它必须在目标剪映 macOS 和 Windows 版本中检查透明通道、边缘质量、时长和音画同步；通过实测前，界面不得标记为“剪映兼容”。

## 授权和订阅

订阅只售卖软件使用权限，不代付或代理用户的云端模型调用费用。

- 试用期为首次激活后的七天；后续支持月、季、年订阅。
- 同一账号最多绑定三台设备。
- 同一账号同时只能有一个活动会话。
- 新设备登录会撤销旧设备会话；旧设备在下一次联网、触发 AI 或关键操作时失效。
- 本地查看和编辑最多允许连续离线两小时。
- 每次触发 AI 流程都在线检测订阅；检测成功后两小时内不重复校验。
- 设备身份由硬件序列号哈希和安全存储的设备密钥组合。服务端不保存原始硬件序列号。
- 更换电脑时，用户可在设备管理中停用旧设备并激活新设备；设备损坏时提供有限自助解绑和人工申诉。

两小时离线窗口意味着断网旧设备无法被服务器即时阻断；在旧设备恢复联网、触发 AI 或关键操作时收敛到单一活动会话。

## 验收和测试

核心流程：

- 导入文稿与单条音频/视频后，生成可编辑时间戳字幕和初版时间线。
- 任一已配置且在线的模型记录都只能生成符合 schema 的剪辑计划。
- 用户修改文字、换行、字体、卡片及其他资源后，人工调整不因 AI 重算丢失。
- 纯音频项目自动使用默认背景图。
- 所有资源的添加、替换、删除、复制、移动和时长调整同步到预览。

资源和项目：

- 导入风格包后，背景、卡片、时间轴和曲线图支持预览、分类、搜索与收藏。
- 编辑器不能创建资源库条目。
- 多项目互相隔离，共享资源库引用有效；重新打开项目后时间线、样式和导出设置一致。
- 新建项目缺少媒体或文稿时不可提交。
- 选中资源外框与文字时，右栏正确切换到资源选择或文字属性。

导出：

- HEVC 普通导出在指定目录生成正确分辨率、画幅和音画同步的视频。
- 导出显示真实进度并可安全取消。
- 透明 ProRes 4444 仅在剪映 macOS、Windows 目标版本实测 Alpha、边缘、时长和同步均正确后标记兼容。

授权：

- 每账号最多三台绑定设备、只有一个活动会话。
- 新设备激活后旧设备在下一次联网、AI 或关键操作时失效。
- 校验通过后两小时不重复校验；超过窗口或触发 AI 时在线验证。
- 试用期结束或订阅失效时禁止 AI，但允许查看和编辑已有工程。
