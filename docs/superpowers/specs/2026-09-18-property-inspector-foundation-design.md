# 属性检查器基础设计

日期：2026-09-18

## 目标

完成 Edward 0.7.0 的属性检查器基础：每个可编辑属性有统一的数据合同、中文显示名、默认值、偏好记录和可选关键帧能力；循环动画和 In/Out 转场均在预览中真实生效。闭合矩形无描边缺口属于该注释组件自身的补充，不属于通用属性或渲染规则。

## 范围

- 删除检查器中的“名称”字段。
- 将属性分区、字段与下拉选项译为中文；项目保存的内部属性键保持不变。
- 创建偏好方案 A（最高频）、B（备选）、C（备选）。当前方案决定新组件创建时取用的偏好，也决定检查器确认修改时写入的偏好。
- 建立统一属性合同。每个属性定义内部键、中文名、默认值、类型、适用素材、是否可关键帧、是否写入偏好。
- 双击属性名称恢复默认值；成组属性同时恢复全部字段，删除相关关键帧，并记录恢复值到当前偏好方案。
- 新增循环动画：无、轻微晃动、轻微跳跃、闪烁、轻微缩放；频率与幅度可调。循环动画采用片段本地时间，不占用 In/Out 动画时段。
- 为允许属性提供关键帧的添加、更新、删除和插值切换。默认插值为三次贝塞尔缓出；可选线性、回弹、缓出、缓入。
- In/Out 转场在片段开始与结束的有效时段实际参与预览合成。执行顺序固定为：关键帧基础值、循环动画叠加、In/Out 转场。

## 数据模型

属性合同是唯一配置源。检查器按其生成控件，偏好写入按其判断，预览读取相同键。新增循环字段为：

- `loopAnimation`：`none`、`gentle-shake`、`gentle-bounce`、`flicker`、`gentle-scale`。
- `loopFrequency`：每秒循环次数。
- `loopAmplitude`：效果幅度。

关键帧沿用每个属性的片段本地时间序列，并新增 `easing`：`cubic-out`、`linear`、`back-out`、`ease-out`、`ease-in`。没有关键帧时使用属性当前值；两个关键帧之间采用前一关键帧的插值预设。

转场继续使用 `transitionIn`、`transitionOut` 及其时长。预览只在各自端点的有效范围计算转场进度，避免覆盖中段及循环动画的持续效果。

## 检查器行为

检查器不显示片段名称。每个字段标签提供双击恢复默认值。具有关键帧资格的字段在标签旁显示关键帧控制，当前播放头存在关键帧时显示其插值下拉列表。

循环动画是独立分区，显示类型、频率、幅度。选择“无”时仍保留频率和幅度值，方便切回原效果。新字段与所有已有可偏好属性通过统一记录入口写入当前方案。

## 预览与渲染

### 统一画布坐标合同

属性检查器、时间线插入、关键帧、预览、直接操作、组件运行时和导出统一使用中心坐标：画布中心为 `(0, 0)`，右/上为正，左/下为负。`x/y` 的存储值不是 DOM 左上角或 Canvas 左上角像素；屏幕坐标和导出像素必须在边界处转换。分辨率变化只允许按画布宽高缩放，禁止改变原点和 Y 轴方向。任何新属性或组件若包含位置数据，必须复用该合同并以回归测试证明中心点、正负方向及预览/导出一致。

闭合圆角矩形注释组件使用单个完整闭合描边路径，避免分段绘制产生接缝；该实现不扩展为其他组件的通用规则。预览帧中的所有属性由统一求值函数计算：先取关键帧插值，再按循环类型加偏移，最后施加 In/Out 转场系数。导出沿用同一帧求值路径。

## 错误边界

- 不支持关键帧的属性不显示关键帧控制。
- 恢复默认值时仅删除该属性的关键帧，不影响其他属性。
- 关键帧时间相同则更新而非重复插入。
- 转场时长超过片段时长时限制为片段可用长度。
- 未知循环类型、插值或旧项目缺失字段均回退到合同默认值。

## 验收与测试

- 闭合圆角矩形路径在起止点连续，且不含额外线段。
- 属性合同覆盖中文显示、默认值、关键帧资格与偏好资格；检查器不再输出名称字段和英文属性标签。
- A/B/C 三套偏好均可写入、读取，并对新组件生效。
- 双击恢复默认值会移除该属性关键帧并写入当前偏好。
- 每个循环动画在不同片段时间产生预期的非恒定结果，频率和幅度影响结果。
- 关键帧默认三次贝塞尔缓出，并可切换线性、回弹、缓出、缓入。
- In/Out 转场在端点改变预览合成值，中段保持正常值。
- 构建、相关单元测试、FableCut 测试通过；最后重启实际 Edward.app 验证。
