# 设置弹窗设计

## 目标

将不需要在剪辑过程中持续操作的应用设置从左栏移出，保持左栏用于资源库，主页用于新建项目与历史项目。

## 范围

- 顶部右侧增加一个“设置”按钮。
- 点击按钮打开一个模态设置面板。
- 面板包含两个标签：`通用` 和 `AI 模型`。
- `通用` 标签承载项目工作目录的选择、输入和应用。
- `AI 模型` 标签承载当前的云端模型新增表单和已保存模型列表。
- 导出分辨率、质量和透明通道继续只在导出面板中选择，不进入通用设置。
- 左栏继续保留资源库；主页继续保留新建项目与历史项目。

## 交互

设置面板默认关闭。点击顶部“设置”按钮打开，点击关闭按钮退出。打开或关闭设置不会切换项目、工作目录或导出状态。

工作目录应用成功后继续发送既有的 `workspace-changed` 事件，刷新资源库和模型数据。模型保存成功后继续更新顶部模型在线状态。

## 实现边界

复用 `WorkspaceSettings` 与 `ModelSettings` 中既有的数据读写逻辑，只将它们的呈现位置移入新的设置弹窗。导出弹窗不改动业务逻辑。

## 验证

- 默认不渲染设置面板。
- 点击顶部设置按钮后，能看到通用标签和工作目录字段。
- 切换到 AI 模型标签后，能看到模型配置字段。
- 关闭后，设置面板从 DOM 移除。
- 原工作目录和模型保存冒烟测试继续通过。
