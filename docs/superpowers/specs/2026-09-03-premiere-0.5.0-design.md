# Edward 0.5.0 Premiere 基础架构设计

## 目标

Edward 0.5.0 完全以 Adobe Premiere Pro 为底层剪辑宿主，使用确定性的 React/HTML/CSS 事实理解、统一视觉 IR 和 Premiere 输出适配器，将口播视频所需的字幕、花字、人名条、卡片、边框、背景及常规动画安全地插入 Premiere 时间线，并在剪辑页公开可编辑参数。

Resolve/Fusion 只属于 0.4.0 历史版本，不进入 0.5.0 的生产链路、验收门或运行时依赖。

## 设计原则

- 解析、级联、布局、绘制和转换全部由程序规则执行，不使用 AI 修改事实结果。
- 每个节点、选择器、伪元素、绘制层、动画属性和关键帧都保留独立记录。
- 继承、引用、百分比和计算表达式在理解层物化为最终绝对值后才进入 IR。
- 转换器不得静默删除或近似任何字段；无法映射的字段必须阻断并给出差异。
- 浏览器事实模型是输入基准；Premiere 是输出宿主；两者之间所有换算必须可追踪和可回读。
- 0.5.0 优先覆盖稳定的 2D 组件，不承诺任意浏览器行为都能生成完全等价的 MOGRT。

## 总体架构

```text
React / JSX / HTML / CSS
          ↓
确定性分流层
          ↓
语法事实层
          ↓
CSS 级联与绝对值物化
          ↓
布局与绘制事实层
          ↓
统一视觉 IR
          ↓
Premiere 输出路由
    ├─ MOGRT 编译/插入（可编辑组件）
    └─ Premiere 原生效果与关键帧（剪辑效果）
          ↓
UXP 写入、回读、日志与验收
```

## 分层职责

### 输入分流层

根据文件类型、语法标记和解析结果确定输入类别：React/JSX、HTML、CSS/SCSS、纯文本、MOGRT 参数和 Premiere 原生操作。分流结果包含原文哈希、来源位置、解析器版本和不确定性列表。

### 事实理解层

React/HTML 形成完整节点树；CSS 记录规则匹配、优先级、继承链、变量展开、伪元素和媒体条件；所有属性同时保留原始声明、解析值、级联值、计算值、used value、最终绝对值和来源路径。

### 布局与绘制层

计算盒模型、格式化上下文、Flex/Grid、定位、文本度量、圆角、边框、渐变、阴影、滤镜、裁切、混合、绘制顺序和动画采样。所有相对单位在固定视口、DPI、字体和时间点下物化为确定值。

### 统一视觉 IR

IR 节点包含稳定 ID、父子关系、包围盒、锚点、变换矩阵、可见性、颜色空间、绘制层、效果链、文本信息、关键帧和来源映射。每个字段都必须有映射状态和证据位置。

### Premiere 输出层

MOGRT 路由把形状、文本、效果和关键帧编译为 After Effects 图层并导出模板；UXP 负责导入模板、设置公开参数、放置到当前序列并回读。剪辑效果路由只调用已验证的 Premiere 原生效果和关键帧 API。

## MOGRT 参数模型

公开参数分为内容、视觉、布局和动画四组：文字/字体/字号/字距/行距、颜色/渐变/圆角/边框/阴影、位置/缩放/旋转/锚点、透明度/淡入淡出/位移/缓动/循环。参数必须来自 IR 的稳定字段路径，不能由 UXP 或模型重新猜测。

## 错误与差异处理

每次事务生成输入哈希、IR 哈希、MOGRT 哈希、目标序列标识、插入位置、参数回读和字段映射清单。状态只允许 `mapped`、`unsupported`、`blocked`。存在未映射字段、回读不一致、关键帧缺失、序列定位失败或像素差异超阈值时，禁止写入成功和完成报告。

## 版本边界

- 0.4.0：Resolve/Fusion 维护版，冻结现有路线。
- 0.5.0：Premiere-only；不链接 Resolve SDK、Fusion 写入器或 Resolve 验收脚本。
- 0.5.0 首批交付目标：可编辑 2D MOGRT、Premiere 原生效果关键帧、UXP 插入/回读/日志闭环。
- 浏览器独有且无法表达为 MOGRT 的语义必须在转换前报告，不得静默降级。

## 验收标准

1. 同一输入重复运行得到相同分流结果、事实快照和 IR 哈希。
2. 复杂嵌套、继承、变量、媒体条件、伪元素和关键帧的字段均有独立记录。
3. MOGRT 插入 Premiere 后，公开参数可在剪辑页修改并被 UXP 正确回读。
4. 序列、轨道、时间、锚点和包围盒换算通过自动断言。
5. 浏览器基准帧与 Premiere 渲染帧完成可量化像素对照；差异未获授权时阻断。
6. 每类事实具有复杂 fixture、快照哈希、IR 字段路径、后端回执和独立断言 ID。
