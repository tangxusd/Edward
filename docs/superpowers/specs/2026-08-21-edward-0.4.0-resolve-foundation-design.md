# Edward 0.4.0 Resolve Studio 基座规格

## 目标

Edward 0.4.0 以 DaVinci Resolve Studio 专业版为剪辑、合成、播放和导出基座。Edward 自身作为独立外部应用，提供面向剪映用户的简化操作层和 AI 能力，不重新实现完整非线性编辑引擎。

## 已确认边界

- 只支持用户已安装的 DaVinci Resolve Studio，不适配免费版。
- Edward 启动时检测 Resolve Studio；未运行时提示用户先启动 Resolve。
- Edward 不作为 Resolve 内部插件安装，不修改 Resolve 的安装目录或核心文件。
- Edward 通过 Resolve Studio 官方脚本 API 及受控适配器执行项目、媒体、时间线、Fusion 和渲染操作。
- `davinci-resolve-mcp` 可作为通信实现参考或 MIT 许可组件，必须保留其许可和版权声明；它不是视频引擎。

## 职责分工

### Resolve Studio

- 项目、媒体池、轨道、剪辑片段、播放头和时间码
- 视频/音频播放
- Fusion 合成、节点和关键帧执行
- 最终渲染、导出和工程保存

### Edward

- AI 对话和技能编排
- 外部组件资源库、用户上传、审核状态和积分
- HTML/React/Remotion/HyperFrames 到统一 Component IR 的转换
- 剪映式属性编辑、关键帧和贝塞尔曲线编辑
- 预览窗拖拽、坐标换算和组件定位
- 字幕、组件及 AI 生成素材的添加流程
- 常用导出参数和进度界面

Edward 和 Resolve 保留两套相互独立的导出通道：

- Edward 导出：覆盖稳定的常用参数，面向不熟悉 Resolve 的用户；通过适配器调用 Resolve Studio 执行渲染。
- Resolve 导出：保留 Resolve Studio 原生 Deliver 页面和全部高级参数，面向高级用户；不依赖 Edward 导出面板。

两套通道共享 Resolve 的项目和渲染引擎，但不共享 UI 状态。Edward 导出失败时不得阻止用户转到 Resolve 原生导出；Resolve 原生导出也不得被 Edward 的简化参数覆盖。

## 窗口协同

Edward 使用独立窗口作为 Resolve 的侧栏式控制面板。Resolve 的原生预览和时间线保持为真实状态，Edward 只显示同步的操作视图，不维护第二套独立时间线真相。

- 单屏：Resolve 主窗口与 Edward 侧栏按可配置比例排列。
- 多屏：默认 Resolve 占用主屏，Edward 占用副屏；用户可在设置中交换屏幕。
- Edward 关闭后不影响 Resolve；Resolve 退出或断开时，Edward 显示连接状态并停止写入操作。
- 不依赖系统级模拟点击隐藏 Resolve 面板。Edward 提供自己的简化工作区；Resolve 的复杂页面保留为高级回退入口。

## 统一组件管线

```text
AI / 资源库 / 外部插件
        |
        v
   Component IR
        |
  属性与关键帧编辑
        |
  Resolve Adapter
        |
 Fusion / Resolve 时间线
        |
 Resolve 预览与渲染
```

Component IR 是组件的编辑真相，至少包含组件树、画布尺寸、时间范围、位置、缩放、旋转、不透明度、样式、关键帧、贝塞尔曲线、资源引用和来源信息。不同来源的组件必须先转换为该格式，禁止直接把不同渲染器的内部格式混入公开资源库。

0.4.0 只保证标准 Component IR 子集的可编辑转换，不承诺任意 HTML、React、Remotion 或 HyperFrames 内容都能等价转换。无法转换的属性必须在转换报告中明确列出；组件仍保留原始草稿，并允许以透明视频作为受控渲染回退，不得静默丢失效果。

## 坐标和播放头

- 预览中心为 `(0, 0)`。
- 向左为正 X，向右为负 X。
- 向上为正 Y，向下为负 Y。
- Edward 读取 Resolve 的当前播放头帧、时间码、帧率和时间线起点。
- 在当前播放头写入或修改关键帧；Edward 先更新 Component IR，再转换为 Fusion/Resolve 操作。
- 播放头变化通过适配器轮询或事件同步；轮询只用于读取状态，不在每次读取时重写 Fusion。

## 第一条垂直切片

优先实现“字幕组件”而不是完整动画编辑器：

1. 读取本地视频或音频并完成转写。
2. 生成字幕 Component IR。
3. 在 Edward 中编辑字幕文字、时间、字体、位置和关键帧。
4. 转换为 Resolve/Fusion 可执行对象并添加到时间线。
5. 以 Resolve 预览为准验证，调用 Resolve 渲染导出。

## 失败和回退

- Resolve 未运行：阻止写入并提示启动。
- 适配器断开：保留本地 IR 草稿，禁止声称已写入 Resolve。
- IR 无法完整转换：明确标记不支持的属性，不静默丢弃；允许导出透明视频作为受控回退。
- Resolve 原生高级功能：从 Edward 回退到对应 Resolve 页面，不复制其全部界面。

## 0.4.0 验收门

- 可检测并连接 Resolve Studio。
- 可读取项目、当前时间线、播放头、帧率和轨道。
- 可把一个字幕 Component IR 添加到 Resolve 时间线并在预览中显示。
- 可在播放头位置修改字幕属性并写入关键帧。
- 可通过 Edward 发起一次 Resolve 渲染并显示状态。
- 可从 Edward 发起常用参数导出，也可独立转到 Resolve 原生高级导出。
- 断开、Resolve 退出和转换失败均有可观察错误，且本地草稿不丢失。
