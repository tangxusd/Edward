# Edward 0.6.0 FableCut 视觉布局规范

## 已确认布局

页面保持左侧资源区、中间编辑区和右侧属性栏三列结构。中间编辑区内部保持上部节目监视器、下部时间线；右侧属性栏从窗口内容区顶部一直延伸到窗口底部，宽度沿用当前值。

```text
┌────────资源区────────┬────────────预览区────────────┬──属性栏──┐
│                      │                            │          │
│                      │                            │          │
├──────────────────────┴────────────────────────────┤          │
│                  时间线与工具栏                    │          │
└────────────────────────────────────────────────────┴──────────┘
```

时间线只横跨资源区和预览区，不进入右侧属性栏。右侧属性栏独立滚动，页面缩放和窗口尺寸变化不得导致面板重叠或内容不可访问。

## 视觉规则

- 深黑灰背景、低对比边框、浅灰主文字和中灰次要文字。
- 沿用当前紫色交互强调色，不改变功能识别。
- 保持现有小圆角和紧凑间距，不引入卡片化布局。
- 属性分组使用紧凑标题、细分隔线和窄行高。
- 保留现有中文/英文界面、Adjust、画面调节、属性双击回退和时间线功能。

## 验收标准

- 属性栏顶部与窗口内容区顶部对齐，底部与窗口底部对齐。
- 时间线横跨左侧资源区和中间预览区。
- 属性栏内容独立滚动；拖动时间线、编辑属性、窗口缩放均无重叠。
- 现有界面语言切换、Adjust 和属性双击回退继续可用。
