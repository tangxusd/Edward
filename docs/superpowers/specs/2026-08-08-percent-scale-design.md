# 属性面板百分比缩放设计

## 目标

为预览画布中已选中的卡片、图形和字幕提供右侧属性面板百分比缩放，替代依赖拖拽修饰键的自由缩放操作。

## 范围

- 属性面板只显示一个缩放值，单位为百分比。
- 缩放始终统一联动宽高，不提供独立的水平、垂直缩放或比例锁定开关。
- 每次修改立即更新预览、项目持久化数据、撤销/重做和自动保存。

## 数据与交互

百分比以该元素首次缩放前的布局宽高为参照；布局保存基准宽高和缩放百分比，使项目重开后仍显示正确的缩放值。卡片、图形和字幕复用同一套属性面板逻辑；未选中资源时不显示缩放控件。

## 验证

- 选中卡片后可见缩放属性。
- 修改缩放百分比，预览布局宽高按相同比例更新并持久化。
